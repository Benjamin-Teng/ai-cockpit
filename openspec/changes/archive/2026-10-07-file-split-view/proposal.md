# file-split-view

## Why

檔案分頁一次只能看一個檔案。對照規格與設計、README 與 handover 這類「邊看邊比」的閱讀，只能在分頁間來回切換。
另外，Markdown 內文的最大行寬約 80ch，在高解析大螢幕上單欄閱讀會在右側留下大片空白。使用者 2026-10-04 提出要能
同時並排閱讀 2～3 個檔案。brainstorming 定案的範圍是：只有檔案分頁能並排，沿用單一分頁列，欄寬固定等寬，
點擊規則採「焦點欄替換」。

## What Changes

- **檔案並排**：每個檔案分頁多一個「並排」切換鈕（Ctrl＋點分頁效果相同），最多 3 個檔案分頁同時等寬並排顯示。
  並排中的分頁在分頁列上帶欄位編號標記。
- **焦點欄**：並排時恰有一欄是焦點欄，外框以強調色標示，點欄內任何位置就成為焦點欄。焦點欄對應的分頁就是目前分頁。
  並排中以一般方式點選不在並排裡的檔案分頁（含從檔案樹開檔、點 md 相對連結），只替換焦點欄，其他欄不動。
  已滿 3 欄時再按「並排」也是替換焦點欄。
- **離開並排**：再按一次「並排」或關閉並排中的分頁，就把該分頁移出；剩一個時自動回到單欄。
- **非檔案分頁不參與**：Live Output、diff、Git Graph、某版本檔案分頁不能加入並排。選到它們時只顯示該分頁，並排組合保留，
  點回並排中任一分頁時整組恢復。
- **窄視窗**：視窗寬度小於 760 CSS px 時只顯示焦點欄，放寬後恢復並排。
- **自動更新改為「每個可見的檔案分頁」**：從「只有目前分頁」改為所有畫面上可見的檔案分頁各自定時查詢。
  沒有並排時行為與現在相同。
- **分頁還原**：並排組合一起存進瀏覽器本機儲存並還原，本 change 之前的格式照常還原為沒有並排。

## 非目標

- **不做 VS Code 式的編輯群組**：每欄沒有各自的分頁列，也不能把分頁拖到別欄。
- **不做可拖曳的欄寬**：欄寬固定等寬，不記憶比例。
- **不設每欄最小寬度，也不自動減少欄數**：窄視窗（例如 800 寬）切三欄時，每欄會很窄，由使用者自行把一欄移出。
  這是使用者 2026-10-06 在 task 4.1 設計審核時裁決的。
- **停用的並排鈕不隱藏**：沒有可配對的分頁時，目前分頁上的並排鈕照常顯示，只是停用。這樣使用者看得到有並排功能，
  滑鼠移上去時，`title` 會說明原因（同一天裁決）。
- **不做同步捲動**。
- **不做水平（上下）分割**。
- **不調整 Markdown 的 80ch 行寬上限與單欄時的置中**：並排時每欄自然變窄。單欄右側空白另案處理。
- **非檔案分頁不並排**：Live Output 有固定位置與自己的輪詢（`live-output`），git 類分頁的輪詢目前只能有一份（見 design）。
- **不動後端**：沒有新端點、不改投影 JSON 與 WebSocket 推送（設計文件 §6.4、§8.1），也不新增任何 HERDR method
  （設計文件 §2、ADR-0001）。並排純屬前端畫面上的狀態，只存在於瀏覽器本機。
- 畫面整體三欄版面不變（設計文件 §8.3；`cockpit-dashboard`「版面與窄視窗」），並排只發生在中欄下半部分頁區內部。

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `file-review`：
  - 新增「檔案並排」需求。
  - 修改「檔案分頁」：目前分頁在並排時的定義、點選與關閉的語意。
  - 修改「自動更新」：改為每個可見的檔案分頁各自查詢，並重新定義舊回應何時丟棄。
  - 修改「分頁還原」：加入並排組合，並相容舊格式。

## Impact

- 前端：
  - `cockpit/assets/app/files.js`：分頁狀態加入並排組合，分頁生命週期從「是否為目前分頁」改為「是否可見」，
    輪詢從全域一條改為每個分頁各一條，localStorage `cockpit.fileTabs` 在 v2 上加可選的並排欄位，不升版號，
    回滾到舊版時分頁不會遺失。
  - `cockpit/assets/app/style.css`：並排的 grid、焦點欄外框、並排鈕與欄位編號標記。
  - `cockpit/assets/index.html`：只在需要時微調分頁區容器。
- 後端 Rust 不改；`cockpit/examples/ui_preview.rs` 只在現有 fixture 不足以驗收時補檔案。
- 驗收腳本：新增 `docs/research/<日期>/split-check.js` 與 `split-check.md`；既有的 `files-check.js`、
  `git-check.js` 要全數回歸通過。
- 文件：`CONTEXT.md` 新增「檔案並排」「焦點欄」詞條，另更新 `cockpit/README.md` 與 `docs/handover.md`。
  `docs/handover.md` 依使用者指示改由「自動更新管理」session 在兩個 change 都發版後統一重寫（見 tasks.md 5.4 的註）。
